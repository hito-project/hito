# 0010. Project name: HITO

- **Status:** Accepted
- **Date:** 2026-10-08

## Context

The project owner wanted a recursive acronym whose first word has its own meaning.

## Decision

The project is named **HITO**: *HITO Is Totally Open*.

A *hito* is a survey marker, a fixed reference point that surveyors measure from. In Spanish the word also means landmark and milestone.
