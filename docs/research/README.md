# Research

Research lives in [GitHub Discussions (Research)](https://github.com/hito-project/hito/discussions/categories/research), where it can be commented on and extended. Each discussion cites its sources.

| Discussion | Question it answers |
|---|---|
| [Revit capabilities](https://github.com/hito-project/hito/discussions/74) | What does Revit do, and what makes it BIM rather than CAD? |
| [Civil engineer workflows](https://github.com/hito-project/hito/discussions/75) | How do civil engineers work day to day, especially in Argentina? |
| [AEC software landscape](https://github.com/hito-project/hito/discussions/76) | Which programs do civil engineers use, and for what? |
| [Why AEC software is split into separate products](https://github.com/hito-project/hito/discussions/77) | Why is AEC software split into many products instead of one? |
| [Industry pain points](https://github.com/hito-project/hito/discussions/78) | What frustrates AEC professionals about their software? |
| [Prior art](https://github.com/hito-project/hito/discussions/79) | Which existing projects should we learn from or integrate with? |

New research goes in a new discussion in the Research category. Research that leads to a decision ends in an ADR in [decisions/](../decisions/README.md).
