# Target user

## Founding user

A civil engineer in Argentina who:

- uses Revit professionally and describes it as "CAD, but in 3D, with metadata embedded into the model, like cables, pipes, etc.",
- would switch to Linux if Revit did not keep them on Windows.

Their specific workflow hasn't been gathered yet. Common workflows stand in for it.

## Broader audience

- Civil engineers across disciplines (buildings, structures, infrastructure, water) who currently juggle several separate programs.
- AEC professionals who want to leave Windows, or who are priced out of Autodesk subscriptions.
- Users of Revit, AutoCAD and CYPE. The UI should feel familiar to them ([ADR 0007](../decisions/0007-ui-familiar-to-current-users.md)).
- Argentina first, then any country through pluggable design codes and standards ([ADR 0008](../decisions/0008-argentina-first-international-by-design.md)).
- Small firms and individuals who work across disciplines and would benefit most from a unified core ([architecture/unified-core.md](../architecture/unified-core.md)).
- Companies wanting customisation, served through consulting ([ADR 0009](../decisions/0009-license.md)).
