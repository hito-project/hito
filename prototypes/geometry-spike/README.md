# Geometry kernel spike (#2)

Throwaway prototypes for [spike #2](https://github.com/hito-project/hito/issues/2). Each `k-*` binary builds the same test cases with one kernel and prints a tab-separated table. Results and the comparison are in the "Geometry kernel evaluation" Research discussion. The decision is in `docs/decisions/0014-geometry-kernel.md`.

This code isn't part of HITO and won't be merged.

## Cases

All cases are defined in [`common/src/lib.rs`](common/src/lib.rs). Volumes are measured the same way for every kernel: on the output triangle mesh, shifted to its first vertex.

| Case | What it tests |
|---|---|
| `wall-window` | A 5 m x 0.2 m x 3 m wall minus a 1.2 x 1.2 m window. The issue's basic case. |
| `wall-door` | The same wall minus a door that starts at the wall's base, so the two solids share a face (a coplanar boolean). Real doors do this. |
| `plate-200-holes` | A 2 m x 1 m x 20 mm steel plate with 200 bolt holes of 22 mm, subtracted one by one. The detailing robustness test from Discussion #87. |
| `plate-200-holes-batched` | The same, with the holes combined first and subtracted once |
| `corridor-sweep`, `corridor-minus-culvert` | A 12 m x 1 m section swept along a 200 m clothoid at 3% grade, generated by our own code (SR-1), then cut by a box culvert. Only for kernels that accept meshes. |
| `10k-walls` / `1k-walls` | 10,000 walls with windows, at Gauss-Krüger-like coordinates (about 6,000,000 m north), for timing and precision far from the origin. Slower kernels run 1,000. |

## Running

Rust isn't installed system-wide, so commands go through nix:

```sh
nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc -c cargo run --release -p k-boolmesh
nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc -c cargo run --release -p k-truck
nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc -c cargo run --release -p k-monstertruck
nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc nixpkgs#git -c cargo run --release -p k-csgrs

# Manifold: link nixpkgs' prebuilt library instead of cloning and compiling it.
MANIFOLD_CSG_LIB_DIR=$(nix build nixpkgs#manifold --no-link --print-out-paths)/lib \
LD_LIBRARY_PATH=$MANIFOLD_CSG_LIB_DIR \
  nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc -c cargo run --release -p k-manifold

# OpenCascade: built on its own. The binding needs OCCT 7.8 and doesn't compile
# against nixpkgs' 7.9.3, so it compiles the bundled OCCT from source.
CMAKE_POLICY_VERSION_MINIMUM=3.5 \
  nix shell nixpkgs#cargo nixpkgs#rustc nixpkgs#gcc nixpkgs#cmake nixpkgs#gnumake \
  -c cargo run --release --manifest-path k-occt/Cargo.toml
```

`results/` holds the output of the runs reported in the discussion.
